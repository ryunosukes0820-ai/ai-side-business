# 01. Brief Analysis — NEXORA AI LP

## 1. 案件概要

NEXORA AI(架空ブランド)の中小企業向けAI業務効率化・導入支援サービス「NEXORA AI」のLP制作案件。**ポートフォリオ掲載用の自主制作・架空案件**であり、実在するサービス・企業ではない。

## 2. LPの目的

無料相談の申込み獲得。CTA文言(方向性)は「無料相談を申し込む」。

## 3. 確定している情報

- 会社・ブランド名: NEXORA AI
- 業種: 中小企業向けAI業務効率化・導入支援サービス
- 商品・サービス名: NEXORA AI
- サービス概要: 中小企業向けのAI業務効率化・導入支援サービス
- サービス特徴: 業務ヒアリング / AI活用方法の提案 / 業務フローに合わせた導入支援 / AIツール活用支援 / 導入後の運用サポート / オンライン相談対応 / 無料相談あり
- 申込方法: Webから無料相談を申し込む
- メインメッセージ(方向性): 「AIを、現場で使える仕組みに。」
- 補足メッセージ(方向性): 「業務に合わせたAI活用を設計し、導入から運用までサポート。」
- 希望カラー: ダークネイビー / ブルー / シアン / ホワイト
- 希望テイスト: BtoB・AI・SaaS・テクノロジー・信頼感・先進性・モダン・洗練・高級感・スタートアップ感・余白を活かした設計
- デザイン品質の目標: 「実案件で企業に提出しても違和感がないBtoB SaaSサービスサイト」の完成度。FLEXIA・LUMIELより1段階上のクオリティを狙う。単純なカード並び・テンプレート感の強いLPにはしない
- ファーストビューの方向性: 左にコピー・CTA、右にダッシュボード風UI/SaaSプロダクト画面風ビジュアル。Dark Navy・Blue・Cyan基調+gradient・glow・blur・grid・light particle等の装飾。ただしSF的な過剰な未来感は避け、リアルなBtoBデザインにする
- UI表現の方向性: Dashboard mockup・Workflow diagram・Analytics card・Integration card・Browser window mockup・Status indicator・floating UI cards・glassmorphism・gradient border・glow effect等を使用可。**数値実績は表示せず、AUTOMATION/WORKFLOW/AI ASSIST等の抽象ラベルに限定する**
- セクション構成の方向性: セクションごとに背景色・レイアウト・カードサイズ・余白・UI表現を変え、スクロールに変化を持たせる。候補セクション: HERO/PROBLEM/SOLUTION/HOW IT WORKS/FEATURES/USE CASE/SUPPORT/FLOW/FAQ/FINAL CTA/FOOTER。HOW IT WORKSは「業務整理→AI活用設計→導入支援→運用サポート」のフロー表現。FEATURESはBento Gridも検討
- モーション方針: scroll reveal・hover lift・glow transition等の控えめな演出。`prefers-reduced-motion`に対応
- レスポンシブ方針: Mobile(375〜430px)でも作り込まれた印象を維持し、横スクロールを発生させない
- 避けたいデザイン: FLEXIAのような黒一色の高級感、LUMIELのような明るい教育系デザイン、派手すぎるSF表現、テンプレート感の強い一般的なLP、根拠のない実績・数値演出(UIモックアップ内の数値表示を含む)
- 素材方針: ロゴは後工程で制作予定、写真・人物画像はAI生成予定(または抽象グラフィック中心も検討)、商品画像はなし、必要に応じてアイコン・抽象グラフィック・グラデーション装飾を使用
- **架空サービスである旨を、LPのフッター等で分かるように明記する必要がある**(brief指定)

## 4. ターゲットとして確定している情報

- 年齢・性別: 指定なし
- 職業: 中小企業の経営者・事業責任者・管理職
- 生活スタイル: AI活用に興味はあるが、何から始めればよいか分からない。社内にAIの専門人材がおらず、自社で検討を進めにくい

- 理想の状態: 自社の業務に合った形でAIを導入し、現場で実際に使いこなせるようになる

## 5. サービスとして確定している情報

上記3と重複するため要点のみ再掲: 業務ヒアリング・AI活用方法の提案・業務フローに合わせた導入支援・AIツール活用支援・導入後の運用サポート・オンライン相談対応・無料相談あり・Webから申込み。**料金体系は未定義**。**強み・競合との違いについても、根拠のない比較優位を設定しない方針が明記**されている。

## 8. 制作時のリスク・注意点

- **実在のAI導入支援サービス・企業との誤認防止**: フッター等に「本サイトはポートフォリオ制作用の架空サービスです」といった趣旨の明記が必須
- **BtoB領域特有の信頼性配慮**: 具体的な数値実績・導入企業数がない中で、誇大に見えない範囲で信頼感を作る必要がある。サービス内容(ヒアリング→提案→導入支援→運用サポート)の透明性で信頼を構築する方針とする
- **UIモックアップの表現リスク**: ダッシュボード風ビジュアルやAnalytics cardのようなUI表現は、放っておくと"それらしい"数値(削減率グラフ、満足度スコア等)を入れたくなるデザイン領域であるため、STEP06・STEP07で数値を一切使わない抽象UIとして設計する方針を徹底する
- **料金の扱い(確定情報とAI提案の分離)**: 確定情報は「具体的な料金は未設定」「無料相談申込みが最終CTA」のみ。料金をLP上でどう見せるかはSTEP03以降でAIが提案する余地として扱う
- **申込み後フローの扱い**: 無料相談申込み後の具体的な流れ(日程調整・面談方法等)はbrief未確定のため、LP構成・コピーにおいて具体的な手順を創作しない
- **デザイン品質の目標設定**: FLEXIA・LUMIELより1段階上のクオリティを目指す方針が明記されているため、STEP06(デザインガイド)・STEP07(画像プロンプト)では、単純な3カード羅列ではなくBento Grid・Workflow可視化・floating UI等、案件のトーンに見合った作り込みを検討する
- **素材の未確定**: ロゴ・写真・人物画像が現段階で存在しないため、デザイン仕様書・実装は「素材確定後に差し替え可能」な前提で設計する

## 9. STEP02以降へ引き継ぐ重要事項

- ターゲットの悩み(AI活用方法が分からない/どの業務をAI化できるか分からない/専門人材がいない/使いこなせるか不安/業務効率化を進めたい)と理想の状態を、ターゲット分析(02)のインプットの中心に据える

- 差別化方針(根拠のない比較優位を設定しない、確定した支援プロセスの一貫性を訴求する)を、USP設計(03)にそのまま反映する
