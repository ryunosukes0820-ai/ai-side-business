# LP Strategy — NEXORA AI LP

**凡例**: 本文書内では以下を区別して明記する。
- **確定情報**: client-brief.mdに記載されている事実
- **AIによる分析・仮説**: 02_target_analysis.mdで整理した心理・障壁(実際の顧客調査ではない)
- **AIによる提案**: STEP03でAIが考案した訴求・導線・オファーの方向性(クライアント決定済みの方針ではない)

料金・導入企業数・導入実績・売上向上率・作業時間削減率・ROI・顧客満足度・継続率・成功事例・顧客の声・No.1・業界最大・最安・保証・必ず成果が出る・○%改善・○倍改善・専門知識不要・誰でも簡単・絶対・具体的な導入期間・具体的な相談時間は、本文書内で一切使用していない。

## 1. LPの目的

**確定情報**: LPの目的は無料相談の申込み獲得(client-brief.md記載)。

**最終CTA**: 無料相談を申し込む

## 2. コアポジショニング(AIによる提案)

**提案**: NEXORA AIを「AIツールを売るサービス」ではなく、「自社業務を整理し、AIを現場で使える形に設計し、導入から運用まで支援するサービス」として位置づける。

**流れ**: 業務理解 → AI活用設計 → 導入支援 → 運用支援

**根拠(確定情報)**: 業務ヒアリング・AI活用方法の提案・業務フローに合わせた導入支援・AIツール活用支援・導入後の運用サポートという5つの確定特徴が、この4段階の流れと自然に対応する。

## 3. コアUSP(AIによる提案)

**提案**: 「AIツールの導入だけでなく、業務ヒアリングから活用設計・導入支援・運用サポートまでを一貫して伴走する、中小企業向けAI活用支援」

**根拠**: 業務ヒアリング・AI活用方法の提案・業務フローに合わせた導入支援・AIツール活用支援・導入後の運用サポート・オンライン相談・無料相談という、client-brief.mdに確定情報として記載された特徴の組み合わせをUSPとする。競合比較データがないため、「業界No.1」「他社より優れている」「最も」「唯一」「高い成功率」といった比較優位表現は使用していない。

## 4. メインターゲット

**確定情報**: 中小企業の経営者・事業責任者・管理職。AI活用に興味はあるが、何から始めればよいか分からない。社内にAIの専門人材がいない。

**AIによる分析・仮説(02より)**: 経営者・事業責任者は投資判断の観点、管理職は現場導入・定着の観点で関心を持つ可能性がある。

## 5. HEROコピー候補(AIによる提案、5案)

### A案「AIを、現場で使える仕組みに。」(client-brief.md記載の第一候補)
- 強み: シンプルで力強く、「現場で使える」というブランドの核心的価値を一言で伝えられる
- 弱み: 「仕組みに」という体言止めがやや抽象的で、単体では何のサービスか掴みにくい可能性がある
- BtoB向け適合度: 高(簡潔で意思決定者の印象に残りやすい)
- ブランド適合度: 高(コアポジショニングと直接一致)

### B案「AI導入を、「使える仕組み」まで。」
- 強み: 「導入して終わりではない」という差別化ポイント(運用サポートまで)を明確に示せる
- 弱み: 鍵括弧を含む言い回しがやや説明的で、A案よりキャッチーさに欠ける
- BtoB向け適合度: 高
- ブランド適合度: 中〜高

### C案「AI活用を、ツール選びで終わらせない。」
- 強み: 「ツールを導入して終わる」という潜在的な失敗パターンへの共感を強く喚起できる(Objection2と直結)
- 弱み: 否定形の表現でポジティブな期待感がやや弱い
- BtoB向け適合度: 中〜高
- ブランド適合度: 中(差別化は明確だが「現場で使える」という核心メッセージとはやや距離がある)

### D案「自社の業務から考える、AI活用支援。」
- 強み: 「業務理解から始まる」というコアポジショニングの入口を直接的に示せ、説明性が高い
- 弱み: キャッチコピーとしてのインパクトはA〜C案よりやや控えめ
- BtoB向け適合度: 高(業務理解の重要性が伝わりやすい)
- ブランド適合度: 高

### E案「AIを導入する前に、まず業務から整理する。」
- 強み: 「何から始めればいいか分からない」というPainへの直接的な回答になっている
- 弱み: 説明文的で、企業側のメリット訴求としてはやや受け身な印象になる
- BtoB向け適合度: 中〜高
- ブランド適合度: 中〜高

### 採用推奨

**A案「AIを、現場で使える仕組みに。」を第一候補として採用することを提案する。** brief記載の既定方向性であり、ブランドの核心的立ち位置を最も簡潔に表現できるため。A案単体では対象・支援範囲が伝わりにくいという弱みは、サブコピー「業務に合わせたAI活用を設計し、導入から運用までサポート。」を組み合わせることで補完する構成を提案する。D案は「業務ヒアリングから始める」というUSPをより直接的に説明できるため、サブコピーまたはSOLUTIONセクションの見出し候補として保持する。

## 6. サブ訴求(確定情報のみを材料に整理)

- 業務ヒアリングから始める、自社に合わせた活用設計
- 業務フローに合わせた導入支援
- 導入後も続く運用サポート
- オンラインで相談できる、無料相談から始められる安心感

## 7. ベネフィット

機能(確定情報)から想定されるベネフィットを、以下は**すべて仮説**として整理する。効果・成果は断定しない。

- 機能: 業務ヒアリング → ベネフィット仮説: 自社の業務内容を踏まえた提案を受けやすい
- 機能: AI活用方法の提案 → ベネフィット仮説: 「何から始めればいいか分からない」状態から一歩進みやすい
- 機能: 業務フローに合わせた導入支援 → ベネフィット仮説: 現場の実情に合わない導入を避けやすい
- 機能: AIツール活用支援 → ベネフィット仮説: 導入後、使いこなせるかという不安に対応しやすい
- 機能: 導入後の運用サポート → ベネフィット仮説: 導入後も相談先がある安心感を得やすい
- 機能: オンライン相談・無料相談 → ベネフィット仮説: 契約前に、専門知識がなくても話を聞きやすい

## 8. 信頼獲得方針(AIによる提案)

**前提(確定情報)**: 本案件は導入企業数・導入実績・顧客満足度・成功事例・顧客の声のいずれも設定しない架空LPである。

**提案**: 架空の社会的証明(実績・レビュー・数値)は一切作らず、以下の情報で信頼感を作ることを提案する。
- 支援の流れ(業務ヒアリング→提案→導入支援→運用サポート)の透明性を分かりやすく提示する
- 「AI活用イメージ」を、実在企業の事例としてではなく一般的・仮想的な例示として提示する(9章参照)
- 架空制作であることをフッター等で明示し、誠実な情報開示として扱う

## 9. USE CASEの安全な扱い(AIによる提案)

**方針**: 実績・導入事例がないため、USE CASEセクションを設ける場合は「活用イメージ」「こんな業務の整理から相談できます」という**仮想的・一般的な説明**にとどめる。実在企業の導入事例・「○○社で○%改善」等の成功事例は一切作らない。

**業種・業務例の扱いについて**: client-brief.mdには、対応可能な具体的業務(営業・人事・経理・カスタマーサポート等)の確定情報がない。そのため、STEP04以降でこうした業務例をUSE CASEに用いる場合は、「サービスが対応した実績」としてではなく、**「例えば、このような業務の整理から検討できます」という趣旨の例示**であることを明記する方針とする。具体的にどの業務例を挙げるかはSTEP04で検討し、実績断定にならない書き方を徹底する。

## 10. オファー設計

**確定情報**: 確定しているオファーは「無料相談」のみ。料金・割引・特典・キャンペーンは設定しない。

**AIによる提案**: 無料相談を「契約前に、自社の業務に合うか相談できる場」として位置づけ、申込みへの心理的ハードルを下げる導線としてCTAに使うことを提案する。**「勧誘なし」「強引な営業はしません」などの保証は、client-brief.mdに記載がないため付けない(02のObjection仮説をサービス事実に転用しない)。**

## 11. CTA戦略

**最終CTA(確定情報)**: 「無料相談を申し込む」

**配置候補(AIによる提案、3箇所)**:
- HERO
- FEATURES/SOLUTIONへの理解が進んだ直後
- 最終セクション(FINAL CTA)

上記3箇所に絞り、無料相談セクション内での重複CTAは避ける。**サブCTA(ページ内リンク)の検討**: 「支援内容を見る」等のページ内アンカーリンクをHERO内に補助的に置く案はあるが、CTAを増やしすぎないため、詳細な要否はSTEP04(LP構成設計)で判断する。

## 12. 訴求優先順位(STEP02を踏まえ並び替え)

1. 「AI活用の何から始めるか分からない」という悩みへの共感
2. 自社業務に合うか分からないという疑問への言及
3. 導入後の現場定着への不安への言及
4. NEXORA AIの支援内容(業務ヒアリング→活用設計→導入支援→運用サポート)
5. 業務ヒアリングから始まる安心感
6. 導入後の運用サポート
7. 無料相談への導線

STEP02の意思決定プロセス(認知→自社適合の疑問→導入ハードルへの不安→支援内容の理解→相談してみてもよさそう→無料相談)と整合させ、上記の順序を提案する。

## 13. LP全体のストーリー(AIによる提案)

以下の流れでLP全体を構成することを提案する(セクション詳細はSTEP04で設計する)。

1. **Problem**: ターゲットの悩み(活用方法が分からない、業務適合への疑問、専門人材不在)に共感を示す
2. **Insight**: 「AI導入」ではなく「現場で使える仕組み」が必要である、という視点を提示する
3. **Solution**: NEXORA AIのコアポジショニング(業務理解→活用設計→導入支援→運用支援)を示す
4. **How It Works**: 支援の流れを視覚的に示す(**「サービスとして提供している支援内容」の順序を示すものであり、未確定の具体的な期間・回数を事実として作らない**)
5. **Features**: 確定特徴(業務ヒアリング/活用提案/導入支援/活用支援/運用サポート/オンライン相談/無料相談)をベネフィットとともに提示する
6. **Use Case**: 仮想的な活用イメージを、例示であることを明記して提示する(9章参照)
7. **Support**: 導入後の運用サポートを掘り下げる
8. **FAQ**: 確定情報で回答可能な疑問を解消する
9. **Final CTA**: 心理的ハードルの低いCTAで無料相談への申込みを後押しする

## 14. デザイン戦略への申し送り(STEP06向け)

- トーン: 今時のBtoB SaaS / AIスタートアップ。Dark Navy・Blue・Cyanを基調としたpremium tech。FLEXIA(黒一色・高級感・ストイック)、LUMIEL(明るい教育系)とは明確に異なる方向性
- UI表現: Bento Grid、Dashboard mockup、Workflow visualization、floating UI、subtle glassmorphism、glow、gradient borderなどを使用可
- インタラクション: scroll revealなど控えめな演出、`prefers-reduced-motion`対応
- **重要な制約**: UIモックアップ内でも架空の成果数値(削減率・満足度スコア・導入件数等)は一切使用しない。使用可能な抽象表示は WORKFLOW / AUTOMATION / AI ASSIST / INTEGRATION / PROCESS / SUPPORT / ACTIVE / CONNECTED 等、実績数値を必要としないラベルに限定する
- FLEXIA・LUMIELより1段階上のデザインクオリティを目指す方針(client-brief.md指定)を維持する

## 15. STEP04へ引き継ぐ重要事項

- **コアポジショニング**: 業務理解→AI活用設計→導入支援→運用支援という4段階の流れを、LP全体のストーリーの背骨とする
- **メインコピー候補**: A「AIを、現場で使える仕組みに。」(採用推奨) / B「AI導入を、「使える仕組み」まで。」/ C「AI活用を、ツール選びで終わらせない。」/ D「自社の業務から考える、AI活用支援。」(サブコピー・SOLUTION見出し候補として保持) / E「AIを導入する前に、まず業務から整理する。」(いずれも最終確定はSTEP05)
- **サブコピー**: 「業務に合わせたAI活用を設計し、導入から運用までサポート。」(A案と組み合わせる前提)
- **CTA配置**: HERO・FEATURES/SOLUTION理解後・FINAL CTAの3箇所。文言はすべて「無料相談を申し込む」で統一
- **USE CASEの扱い**: 実在事例・成功事例は作らず、仮想的な活用イメージとして例示であることを明記する。業務例(営業・人事・経理等)を挙げる場合も断定的な実績表現にしない
- **主な心理障壁(仮説)**: 失敗への懸念、自社業務への適合性への疑問、社内定着への不安、専門知識面での気後れ、契約への警戒感(いずれも仮説であり、保証表現に転用しない)
- **信頼獲得方針**: 支援の流れの透明性、仮想的な活用イメージの明示、架空制作である旨の明示(架空の社会的証明は作らない)
- **禁止表現**: 料金・導入企業数・導入実績・売上向上率・作業時間削減率・ROI・顧客満足度・継続率・成功事例・顧客の声・No.1・業界最大・最安・保証・必ず成果が出る・○%改善・○倍改善・専門知識不要・誰でも簡単・絶対・具体的な導入期間・具体的な相談時間を、05のLP本文執筆・07の画像プロンプト設計まで一貫して適用する
