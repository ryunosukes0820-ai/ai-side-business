- 生活スタイル: AI活用に興味はあるが、何から始めればよいか分からない。社内にAIの専門人材がおらず、自社で検討を進めにくい
- 年齢・性別: 指定なし(brief記載通り、無理に固定しない)

**仮説(AIによる推測)**:
- 仮説: 経営者・事業責任者は「投資判断」の観点で、管理職は「現場導入・定着」の観点でAI活用を検討している可能性があり、意思決定における関心の重心がやや異なる可能性がある(役職ごとの詳細な違いはbrief未記載のため断定しない)
- 仮説: 自社にIT・AI専任部署がない規模感の企業が中心である可能性が高い(brief「社内にAIの専門人材がいない」から推測。企業規模の具体的な定義はbrief未記載)

## 2. 表面的な悩み(確定情報)

(client-brief.mdより確認できる悩み、そのまま整理)

- AIを導入したいが活用方法が分からない
- どの業務をAI化できるか分からない
- 社内にAIの専門人材がいない
- AIツールを導入しても使いこなせるか不安
- 業務効率化を進めたい

## 3. 悩みの背景にある心理(仮説)

**以下はすべてAIによる仮説であり、事実として確認されたものではありません。**

- 仮説: 「AI」という言葉自体は認知しているが、自社の日々の業務とAIの活用イメージが結びついておらず、何から手をつければよいか判断できずにいる可能性がある
- 仮説: 過去にツール導入(AI以外も含む)を試みたが、社内に定着せず使われなくなった経験、またはそうした話を聞いた経験があり、同じ結果を懸念している可能性がある
- 仮説: 経営者・管理職自身がAIの技術的な詳細を理解しきれておらず、社内で説明・説得する自信が持てずにいる可能性がある

## 4. 意思決定を止めている不安(BtoB特有心理・仮説)

**すべて仮説として整理する(client-brief.mdに直接の記載はない。具体的な失敗事例・費用損失は創作していない)。**

1. **「導入したいが失敗したくない」**: 投資判断を伴うため、うまくいかなかった場合の後戻りコストや社内への説明責任を懸念している可能性がある
2. **「自社のどの業務に使えるのか分からない」**: 一般的なAI活用事例と自社の業務内容が結びつかず、具体的な適用イメージが持てないでいる可能性がある
3. **「ツールだけ渡されても社内で定着しないのではないか」**: 現場のメンバーが使いこなせず、結局元のやり方に戻ってしまうことへの懸念がある可能性がある
4. **「専門知識がなくても相談できるのか」**: AIに詳しくない自分が問い合わせても、話についていけないのではという気後れがある可能性がある
5. **「いきなり契約ではなく、まず話を聞きたい」**: 検討の初期段階でコミットメントの大きい契約を迫られることへの警戒感がある可能性がある

## 5. LPで提示すべき安心材料(確定情報ベース)

上記の不安に対し、client-brief.mdの確定情報の範囲でLPが提示できる安心材料を整理する(仮説ではなく、確定特徴の再構成)。

- 業務ヒアリングから始まる → 「自社の業務が分かってから提案される」という順序が示せる(4-2への対応)
- 業務フローに合わせた導入支援 → 「自社に合わせて考えてもらえる」ことが示せる(4-2・4-1への対応)
- AIツール活用支援 → 「渡して終わりではない」ことが示せる(4-3への対応)
- 導入後の運用サポート → 「導入後も伴走してもらえる」ことが示せる(4-3への対応)
- オンライン相談対応・無料相談あり → 「専門知識がなくても、まず相談できる」「契約前に話だけ聞ける」ことが示せる(4-4・4-5への対応)

## 6. 訴求優先順位(Pain / Need / Appeal / Objection)

### Pain(TOP3、確定情報+仮説)
1. AIを導入したいが、活用方法が分からない(確定)
2. どの業務をAI化できるか分からない(確定)
3. 社内にAIの専門人材がおらず、検討・定着に不安がある(確定+仮説)

### Need(TOP3、確定情報の理想の状態に基づく)
1. 自社の業務に合った形でAIを導入したい(確定)
2. 導入して終わりではなく、現場で実際に使いこなせるようになりたい(確定)
3. 専門知識がなくても、AI活用の検討を進められる状態にしたい(仮説、Painの裏返し)

### Appeal(TOP3〜4、確定特徴からの提案)
1. 業務ヒアリングから始まり、自社の業務に合わせて活用方法を提案してもらえる(確定)
2. 導入支援だけでなく、活用支援・運用サポートまで一貫して伴走してもらえる(確定)
3. オンラインで相談でき、無料相談から始められる(確定)
4. 「AIを導入すること」ではなく「AIを現場で使える仕組みにすること」を目的にしている、という立ち位置(確定情報から導けるUSP方向性。STEP03で確定)

### Objection(TOP3、仮説)
1. 「結局うちの業務には合わないのでは」という適合性への疑問
2. 「導入後、社内で使われなくなるのでは」という定着への疑問
3. 「無料相談のつもりが、強引に契約を迫られるのでは」という警戒感(**仮説にとどめ、LPコピー上で「勧誘なし」等の事実として書かない**)

## 7. 無料相談までの意思決定プロセス(仮説)

**以下はすべてAIによる仮説であり、実際の顧客行動データに基づくものではありません。**

1. **認知/興味**: 「AIを業務に活かせないか」という漠然とした関心。自社の課題(専門人材不足・活用方法が分からない)を意識し始める
2. **自社にも使えるのか疑問**: 「一般的なAI活用事例は聞くが、自社の業務に当てはまるのか」という疑問を持つ
3. **導入ハードルへの不安**: 「失敗しないか」「社内で定着するか」「専門知識がなくても進められるか」という不安(4章参照)
4. **支援内容を理解**: ヒアリング→提案→導入支援→運用サポートという一連の流れを知り、「自社に合わせて考えてもらえそうだ」と感じる
5. **相談してみてもよさそう**: 無料相談であり、契約前に話を聞けることを知り、心理的ハードルが下がる
6. **無料相談申込み**: Webから申し込む、という確定した導線に沿って行動する

## 8. コピーにつながるインサイト(STEP03以降で使用)

ターゲットが反応しやすいと想定される言葉の方向性を、確定情報から導ける範囲で整理する。**「専門知識不要」「誰でも簡単」「絶対に使える」等の断定表現は使用しない。**

- 「AI導入」ではなく「現場で使える仕組み」という結果側の表現

- 「まずは無料相談から」という、契約前に話を聞ける段階があることを示す表現

## 10. STEP03へ引き継ぐポイント

- **最も強い悩み**: 「AIを導入したいが活用方法が分からない」「どの業務をAI化できるか分からない」の2つ(client-brief.md記載の悩みの中でも、サービスの強み「業務ヒアリングからの導入支援」と直接対応するため)
- **最も強い欲求**: 「自社の業務に合った形でAIを導入し、現場で実際に使いこなせるようになる」(client-brief.md記載の理想の状態そのもの)
- **主要な心理障壁(仮説)**: 失敗への懸念、自社業務への適合性への疑問、社内定着への不安、専門知識面での気後れ、契約への警戒感
- **有力な訴求候補(まだ確定しない)**: 「AIを、現場で使える仕組みに。」というメインメッセージ方向性は、Need・Appealと整合している。「業務整理から始める」「導入後も運用まで伴走する」という2点を、STEP03のUSP候補として中心に据えることを提案する
- **表現上の注意点**: 「専門知識不要」「誰でも簡単」「絶対に使える」等の断定は行わない。Objectionの「強引な勧誘への警戒」は仮説にとどめ、「勧誘なし」等の保証表現に転用しない。ROI・削減率・満足度等の数値実績は、UIモックアップ内も含め一切使用しない
