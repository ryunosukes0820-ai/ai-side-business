# 01. Brief Analysis — LUMIEL ENGLISH LP

## 1. 案件概要

LUMIEL ENGLISH(架空ブランド)のオンライン英会話サービス「LUMIEL ENGLISH」のLP制作案件。**ポートフォリオ掲載用の架空制作**であり、実在するサービス・企業ではない。

## 2. LPの目的

無料体験レッスンの申込み獲得。CTA文言は「無料体験レッスンを予約する」。

## 3. 確定している情報

- 会社・ブランド名: LUMIEL ENGLISH
- 業種: オンライン英会話サービス
- 商品・サービス名: LUMIEL ENGLISH
- サービス概要: 初心者向けのオンライン英会話サービス
- サービス特徴: 初心者向けオンライン英会話 / マンツーマンレッスン / 1回25分 / オンライン完結 / PC・スマートフォンから受講可能 / 日本語での学習サポートあり / レッスン後に簡単なフィードバックあり / 無料体験レッスンあり / 予約制
- 強み: 忙しい会社員でも継続しやすいことを重視したサービス設計(1回25分・オンライン完結・予約制)
- 差別化方針: 具体的な競合比較データがないため特定の競合との優位性は訴求せず、「忙しい英語初心者でも、1回25分から会話練習を習慣にできる」という継続しやすさを中心に訴求する
- 申込方法: Webから無料体験レッスンを申し込む
- メインメッセージ: 「忙しい英語初心者でも、1回25分から会話練習を習慣にできる。」
- 希望カラー: ホワイト / 明るいブルー / ネイビー / 少量のオレンジまたはイエロー(アクセント)
- 希望テイスト: 明るい・親しみやすい・清潔感・安心感・初心者でも始めやすい印象・社会人向けの爽やかさ・信頼感
- 避けたいデザイン: 黒ベースの高級感を出しすぎたデザイン(FLEXIA案件との差別化) / 過度に高級感を出す表現 / 子ども向け英会話のような幼いデザイン / 派手すぎるグラデーション / 実績を誇張する表現
- 素材方針: ロゴは後工程で制作予定、写真・人物画像はAI生成予定、商品画像はなし、必要に応じてアイコン・抽象グラフィックを使用
- **架空サービスである旨を、LPのフッター等で分かるように明記する必要がある**(brief指定)

## 4. ターゲットとして確定している情報

- 年齢: 25〜39歳
- 性別: 指定なし(男女問わず会社員を想定)
- 職業: 会社員
- 生活スタイル: 仕事が忙しく、英語学習にまとまった時間を確保しづらい。英語を話せるようになりたいが、何から始めればよいか分からない初心者
- 主な悩み: 英語を話せるようになりたい / 英会話初心者でレッスンについていけるか不安 / 仕事が忙しく学習時間を確保しづらい / 独学だけでは会話練習が不足している / オンライン英会話を始めたいがサービス選びに迷っている
- 理想の状態: 忙しい生活の中でも無理なく英語学習を習慣化し、会話練習を継続できるようになる

## 5. サービスとして確定している情報

## 7. 仮定してはいけない情報

briefで明示的に捏造禁止とされている項目:

- 料金 / 講師人数 / 講師の国籍
- 利用者数 / 満足度 / 継続率 / 実績数
- 受講者の声
- 資格・受賞歴
- 効果保証(「必ず話せるようになる」等の断定表現を含む)

以下の断定・誇大表現も使用しない(brief指定): 「必ず話せるようになる」「絶対に上達する」「100%」「業界No.1」「最短○日でペラペラ」

および、根拠のない競合比較優位も作らない(brief指定の差別化方針は「継続しやすさの訴求」であり、他社との性能比較ではない)。

## 8. 制作時のリスク・注意点

- **実在のオンライン英会話サービス・企業との誤認防止**: フッター等に「本サイトはポートフォリオ制作用の架空サービスです」といった趣旨の明記が必須
- **メインメッセージの表現上の注意点**: 「忙しい英語初心者でも、1回25分から会話練習を習慣にできる」という中心訴求について、「習慣にできる」を成果保証のように断定しないよう注意する。具体的には以下を避ける。
  - 「必ず習慣化できます」「誰でも続けられます」のような結果を保証する言い切り表現
  - 継続できなかった場合の責任がユーザー側にあるかのような表現
  - 「話せるようになる」という効果そのものを断定する表現(brief指定の禁止表現と直接抵触するため)
  - 望ましい方向性としては、「1回25分・オンライン完結・予約制」という**サービス設計の特徴**が継続のしやすさに寄与する、という機能ベースの説明にとどめ、「習慣化できる」は仮説・期待値として提示する(断定を避けた表現、例:「〜を目指せる設計です」「〜しやすい環境です」)
- **英語学習・語学教育領域への配慮**: 効果・上達を保証する表現は景品表示法上の優良誤認リスクにもつながり得るため、断定的な効果表現は使用しない
- **料金の扱い(確定情報とAI提案の分離)**: 確定情報は「具体的な料金は未設定」「無料体験レッスン申込みが最終CTA」のみ。料金をLP上でどう見せるか、料金未設定のままどのような導線・表現にするかはclient-brief.mdで確定しておらず、STEP03以降でAIが提案する余地として扱う
- **初心者向けトーンの一貫性**: 「英会話初心者でレッスンについていけるか不安」という悩みに対応するため、専門用語を避け、平易で親しみやすい言葉遣いを心がける。デザイン面でも「子ども向け英会話のような幼いデザイン」は避けつつ、社会人が安心して始められる清潔感・信頼感を両立させる
- **FLEXIA案件との差別化**: 黒ベース・高級感重視のFLEXIAとは異なり、明るいブルー・ネイビー・アクセントカラーを基調とした「爽やか・親しみやすい」トーンで統一する
- **素材の未確定**: ロゴ・写真・人物画像が現段階で存在しないため、デザイン仕様書・実装は「素材確定後に差し替え可能」な前提で設計する

## 9. STEP02以降へ引き継ぐ重要事項

- ターゲットの悩み(話せるようになりたい/初心者でついていけるか不安/忙しくて学習時間を確保しづらい/独学では会話練習不足/サービス選びに迷う)と理想の状態を、ターゲット分析(02)のインプットの中心に据える
- メインメッセージ「忙しい英語初心者でも、1回25分から会話練習を習慣にできる。」を、LP訴求(03)のコアメッセージとして維持しつつ、「習慣にできる」を断定表現にしない書き方をSTEP03以降で一貫して検討する
- 差別化方針(競合比較ではなく継続しやすさ訴求)を、USP設計(03)にそのまま反映する
- 料金・講師情報・実績・受講者の声・資格について、確定情報は「具体的な金額・数値・固有名詞は未設定」のみ。これらをLP上でどう見せるか(掲載しない、無料体験レッスンで案内する等の具体的な導線・表現)はclient-brief.mdで確定しておらず、STEP03(LP戦略設計)以降でAIが提案し、人間の確認を経て決定する事項として扱う
- 禁止表現リスト(必ず話せるようになる/絶対に上達する/100%/業界No.1/最短○日でペラペラ、および利用者数・満足度・継続率・実績数等の捏造数値)を、05のLP本文執筆まで一貫して適用する
- 「架空サービスである旨の明記」を、04のLP構成の段階でフッター等のセクションに明示的に組み込む
- デザイン方向性(ホワイト・明るいブルー・ネイビー・オレンジ/イエローアクセント、明るく親しみやすい、清潔感・安心感、FLEXIAとは異なるトーン)を06のデザイン仕様書に反映する
