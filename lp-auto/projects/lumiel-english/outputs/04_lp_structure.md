# LP Structure — LUMIEL ENGLISH LP

**凡例**: 【確定情報】client-brief.mdの記載事実 / 【AIによる分析・仮説】02_target_analysis.mdの心理分析 / 【AIによる提案】STEP03・STEP04でAIが考案した訴求・構成・CTA配置(クライアント決定済みの方針ではない)

本文書は「どの順番で何を伝えるか」の設計のみを行う。完成コピーの執筆はSTEP05で行う。

## 1. LP全体の設計方針

- **LPの目的**【確定情報】: 無料体験レッスンの申込み獲得
- **メインターゲット**【確定情報】: 25〜39歳・会社員。英語を話せるようになりたいが何から始めればよいか分からない初心者
- **最重要課題**【AIによる提案・STEP03】: 初心者でも、忙しくても、会話練習を生活に取り入れやすい
- **心理導線**【AIによる提案・STEP03/STEP04】: 自分向けのサービスだと気づく → 悩みに共感する → これなら始めやすそうと感じる → サービス内容を理解する → 初心者でも取り組みやすそうと感じる → 無料体験で試してみようと思う
- **CTA方針**【AIによる提案】: 「無料体験レッスンを予約する」を、HERO・BENEFITS(サービス理解が進んだ直後)・最終セクションの**3箇所**に絞って配置し、CTA過多を避ける
- **デザイントーン**【確定情報+AIによる提案】: 白ベース・明るいブルー・ネイビー・オレンジ/イエローのアクセント。爽やか・清潔感・親しみやすい・社会人向けの教育サービスらしい安心感(FLEXIA案件の黒ベース・高級感とは明確に差別化する)

## 3. 各セクション詳細

### SECTION 01：ファーストビュー(FV)

【目的】
来訪者に「自分向けのサービスだ」と一瞬で伝え、離脱を防ぐ。

【この時点の読者心理】(仮説)
「英語を話せるようになりたいが、忙しいし初心者だし続けられるか分からない」という漠然とした問題意識。

【伝える情報】
ブランド名、メインメッセージ方向性、サブメッセージ方向性、CTA。

【見出し方向性】
STEP03のメインコピー候補のうち、**B案「英会話初心者の一歩を、1回25分から。」を軸**とする(最終コピーはSTEP05で確定)。「初心者」「一歩」「1回25分」という要素で、心理的ハードルの低さを伝える方向性。

【使用可能な確定情報】
ブランド名(LUMIEL ENGLISH)、サービス特徴(初心者向け・マンツーマン・1回25分・オンライン完結・日本語サポート)、CTA文言。

【AIによる提案】
サブコピーでは「忙しい会社員」「マンツーマン」「オンライン完結」「初心者向け」が自然に伝わる方向を検討する(例の方向性: 忙しい会社員でも取り組みやすいマンツーマンのオンライン英会話、といった趣旨。最終文言はSTEP05で調整)。「話せるようになる」「必ず続けられる」等の成果保証表現は使用しない。

【ビジュアル要素の想定】(STEP06向け)
白〜明るいブルーを基調とした背景。オンラインレッスンを想起させる、PC・スマートフォン画面のモックアップ風ビジュアルまたは抽象的なグラフィック(人物の実写は必須としない)。ネイビーやアクセントカラー(オレンジ/イエロー)を差し色として使用し、清潔感と親しみやすさを両立させる。

【CTA】
あり。「無料体験レッスンを予約する」。理由: 来訪直後の関心が高いタイミングで、まず選択肢を示しておくため。

【次セクションへの役割】
「忙しい」「初心者」というキーワードを受けて、次のセクションでターゲットの具体的な悩みへの共感を示す。

### SECTION 02：ターゲットの悩み・共感(PROBLEM)

【目的】
ターゲットに「これは自分のことだ」と感じてもらう。

【この時点の読者心理】(仮説・02より)
過去に英語学習が続かなかった経験から「今度も続かないのでは」と感じている可能性。独学の限界を感じている可能性。

【伝える情報】
client-brief.md記載の悩み(英語を話せるようになりたい/初心者でレッスンについていけるか不安/仕事が忙しく学習時間を確保しづらい/独学だけでは会話練習が不足/オンライン英会話のサービス選びに迷う)。

【見出し方向性】
悩みを問いかける、または列挙する見出し。

【使用可能な確定情報】
client-brief.md記載の5つの悩み。

【AIによる提案】
悩みの提示順序として、最重要課題(初心者かつ忙しく始めづらい)に関連する悩みを最初に置く構成。

【ビジュアル要素の想定】
シンプルなチェックリスト/カード形式(FLEXIA案件のPROBLEMセクションと類似の構造で、色調のみ明るいトーンに変更)。

【CTA】
なし。共感段階での早すぎるCTAは唐突なため。

【次セクションへの役割】
悩みへの共感を踏まえ、LUMIEL ENGLISHの解決アプローチへ接続する。

### SECTION 03：LUMIEL ENGLISHの解決アプローチ(CONCEPT/APPROACH)

【目的】
悩みに対する解決の方向性を示し、「これなら始めやすそうだ」と思わせる。

【この時点の読者心理】(仮説)
「本当に自分でも続けられるのか」という期待と半信半疑の気持ち。

【伝える情報】
「忙しい英語初心者でも、会話練習を生活に取り入れやすい」という設計思想(STEP03のコア訴求)。効果や結果を保証する表現にはしない。

【見出し方向性】
解決の方向性を一言で示す見出し(USP候補の言い換え方向)。

【使用可能な確定情報】
1回25分・オンライン完結・予約制・初心者向けという設計上の特徴。

【AIによる提案】
STEP03のUSP候補(初心者向け・マンツーマン・1回25分・オンライン完結・日本語サポートという設計)をこのセクションで提示する構成。

【ビジュアル要素の想定】
明るい背景(白または淡いブルー)に、シンプルなタイポグラフィ中心のレイアウト。派手なグラデーションは避け、余白を活かした落ち着いた爽やかさを表現する。

【CTA】
なし。

【次セクションへの役割】

### SECTION 04：特徴からわかるメリット(BENEFITS)

【目的】
機能ではなく「得られる変化・メリット」をイメージしてもらい、サービス理解を深める。

【この時点の読者心理】(仮説)
「具体的に何が違うのか、自分にとってどう良いのか知りたい」。

【伝える情報】
03_lp_strategyの特徴→ベネフィット変換をそのまま使用する。

- 1回25分 → まとまった時間を確保しづらい会社員でも、生活に会話練習を取り入れやすい
- マンツーマンレッスン → 周囲を気にせず、自分のペースで会話練習に取り組みやすい
- オンライン完結・PC/スマホ対応 → 通学の移動なしで、手持ちの機器から受けやすい
- 日本語での学習サポートあり → 英語だけでは不安な初心者も、分からないことを相談しやすい
- レッスン後に簡単なフィードバックあり → 受けっぱなしにせず、学習の振り返りがしやすい

【見出し方向性】
特徴を項目立てて見せる見出し(「選ばれる理由」的な言い回しは、比較優位を暗示しないよう「続けやすい理由」等の自己完結型の表現にする)。

【使用可能な確定情報】
上記5つの確定特徴とそのベネフィット仮説。

【AIによる提案】
提示順序(時間の短さ→レッスン形式→受講環境→サポート→フィードバックの順)。

【ビジュアル要素の想定】
アイコン+短文のカードグリッド(5項目)。明るいブルーのアイコン、白背景のカード、ネイビーの見出し文字。

【CTA】
あり。「無料体験レッスンを予約する」。理由: サービス理解が最も進んだ直後の、関心が高いタイミングで設置する。

【次セクションへの役割】
特徴を理解したうえで、より具体的な受講スタイルへつなぐ。

【使用可能な確定情報】

【AIによる提案】

### SECTION 08：FAQ

【この時点の読者心理】(仮説)

【伝える情報(確定情報で回答可能なもののみ)】

- 日本語で相談できますか？
- 無料体験レッスンはありますか？
- レッスン後にフィードバックはありますか？

【実案件では追加確認が必要(現時点では回答を作らない)】

- 講師はどこの国の人か

- キャンセルできるか
- 教材はあるか
- 無料体験後に勧誘されるか

【見出し方向性】
「よくあるご質問」。

【使用可能な確定情報】

【AIによる提案】

【ビジュアル要素の想定】
アコーディオン形式(FLEXIA案件と同様のUIパターンを再利用可能)。

【CTA】
なし(直後のSECTION09で最終CTAを置くため、重複を避ける)。

【次セクションへの役割】
