# LUMIEL ENGLISH Design Guide

本文書は、STEP07完了後のHTML/CSS/JS実装工程でそのまま参照できるデザイン仕様書である。画像生成・実装はまだ行わない。使用コピーは`05_lp_copy.md`の採用コピーに準拠する。

## 1. デザインコンセプト

**「仕事で忙しい社会人が、気負わず始められる、明るく爽やかなオンライン英会話LP」**

- **どんな印象を与えるか**: 明るい・爽やか・清潔感・親しみやすさ・安心感。高級スクールのような権威性や、子ども向け英会話のようなポップさのどちらにも寄らない、社会人向けの「軽やかな信頼感」を重視する
- **何を避けるか**: FLEXIA案件で使用した黒背景中心・暗いジム写真・強いブルー発光・男性的でストイックな高級感表現・大きな暗色面積は使用しない。子ども向け英会話のような過度にポップ・カラフルな表現も避ける

## 2. カラーパレット

| トークン | 用途 | HEX |
|---|---|---|
| Background | 基本の背景(白) | `#FFFFFF` |
| Sub Background | セクションの区切り用の淡いブルー | `#F5F9FF` |
| Primary Blue | CTA・アクセント・リンク | `#245DEB` |
| Primary Blue Hover | CTAホバー時 | `#1D4ABC` |
| Dark Navy | 見出し強調・FINAL CTA背景候補 | `#14213D` |
| Accent Orange | アイコン・マーカー・ワンポイント装飾専用 | `#FFB547` |
| Text | 明背景上のメインテキスト | `#1E293B` |
| Sub Text | 明背景上の補足テキスト | `#64748B` |
| Border | 明背景上のボーダー | `#DDE7F3` |

**アクセシビリティ調整の経緯**: 依頼時のカラー候補`#2F6BFF`は、白背景に対するコントラスト比が約4.499:1、Sub Background(`#F5F9FF`)に対しては約4.258:1で、いずれもWCAG AA(通常テキスト4.5:1)をわずかに下回るか際どい値だったため、実装時の再現性を優先して`#245DEB`に調整した(白背景と5.468:1、Sub Backgroundと5.176:1、ともに十分な余裕でAA適合)。ブランドの「明るいブルー」という方向性は維持している。

**重要な運用ルール**: Accent Orange(`#FFB547`)は白背景に対するコントラスト比が約1.76:1と低く、**本文やCTAラベルなど意味を伝える小さな文字色として単独使用しない**。使用してよいのは、アイコンの塗り・数字バッジ・マーカー・装飾ラインなど、文字情報を伴わない、または十分に大きく太い装飾要素に限定する。文字に近い用途で使う場合は、Dark Navy背景の上(コントラスト比約9.09:1)に限定する。CTAの主色は必ずPrimary Blueとし、オレンジ/イエローと競合させない。

**方針**: 白とSub Backgroundを基調に、Primary Blueを「注目させたい箇所(CTA・リンク・アイコン)」に使用する。Dark Navyは見出しの強調やFINAL CTAセクションの背景候補として、暗色面積を最小限に留めながら使用する。すべての文字色と背景色の組み合わせはWCAG AA(通常テキストで4.5:1、大きい見出しで3:1)を満たすことを実装時に確認する。

## 3. タイポグラフィ

**第一候補(Webフォント)**: 日本語 = Noto Sans JP(Google Fonts) / 英数字 = Inter(Google Fonts)
**CSSフォールバック**: `-apple-system, BlinkMacSystemFont, "Hiragino Kaku Gothic ProN", "Yu Gothic", "Segoe UI", sans-serif`

外部フォント読み込みに失敗してもレイアウトが崩れないよう、フォールバックスタックを必ず設定する。

| 要素 | PC size | SP size | weight | line-height | letter-spacing |
|---|---|---|---|---|---|
| Hero headline(H1) | 56px | 32px | 800 | 1.4 | -0.01em |
| H2(セクション見出し) | 36px | 26px | 800 | 1.5 | 0 |
| H3 | 22px | 18px | 700 | 1.6 | 0 |
| Body | 17px | 15px | 400 | 1.8 | 0 |
| Small text | 13px | 12px | 500 | 1.6 | 0.01em |
| Button | 16px | 15px | 700 | 1.2 | 0.02em |
| English label(eyebrow) | 13px | 12px | 700 | 1.2 | 0.14em(uppercase) |

H1はDesktopで48〜64px程度の指定に対し56pxを採用(FLEXIAの46px→縮小経緯を踏まえ、余裕を持たせつつ極端な巨大化は避けた値)。Mobileでは`clamp()`を用いて自然に縮小できるようにし、極端に小さい文字は使用しない(本文は15px以上を維持)。

## 4. レイアウトシステム

- **最大コンテンツ幅**: 1160px
- **PC左右余白**: 40px
- **タブレット左右余白**: 32px
- **SP左右余白**: 20px
- **セクション上下余白**: PC 104px / タブレット 88px / SP 72px(FLEXIAより軽く、開放感のある余白を意識した値。ただしFLEXIAで判明した「モバイルでもPC値が適用されてしまう」CSSカスケードの不具合を踏まえ、`:root`のデフォルト値はSP値とし、768px以上でタブレット値、1024px以上でPC値に切り替える設計を実装時から採用する)
- **カード間gap**: 24〜28px
- **grid基本ルール**: CSS Gridベース。カードグリッドは明示的な列数指定(3列/2列/1列)で管理する
- **border-radius**: カード20px(FLEXIAの16pxよりやや大きく、柔らかい印象を強める)、ボタン999px(ピル型)、小要素(タグ等)8px
- **shadow**: 明背景カード `0 8px 24px rgba(20, 33, 61, 0.06)`(FLEXIAより軽い影)。Sub Background上のカードは影を弱めるか、ボーダー(`Border`トークン)のみで区切ることも可とする
- **装飾**: 円形・曲線のあしらい(淡いブルーの円形、ドット等)を背景装飾として使用可。ただし装飾過多にしない
- **container設計**: `.container { max-width: 1160px; margin: 0 auto; padding: 0 var(--space-side); }`

**ブレークポイント**: Desktop ≥1024px / Tablet 768〜1023px / Mobile ≤767px(375〜430pxを主対象とする)

## 5. ファーストビュー(SECTION 01)

**使用コピー**: メインコピー「英会話初心者の一歩を、1回25分から。」/ サブコピー「仕事で忙しい毎日にも取り入れやすい、初心者向けマンツーマンオンライン英会話。」/ 補足コピー「マンツーマンレッスン ／ 1回25分 ／ オンライン完結」/ CTA「無料体験レッスンを予約する」

- **PCレイアウト**: 2カラム(第一案)。左=英字ラベル+メインコピー+サブコピー+補足コピー+CTA、右=人物ビジュアル(IMAGE01)。背景はBackground(白)またはSub Background
- **SPレイアウト**: 1カラム縦積み。英字ラベル→メインコピー→サブコピー→CTA→補足コピー→ビジュアルの順
- **コピー配置**: 左揃え、メインコピーを最大サイズで配置
- **CTA配置**: サブコピー・補足コピー直下、左揃え
- **ビジュアル配置**: 右カラム、縦方向中央。IMAGE01(25〜39歳程度の社会人を想起させる、自然で爽やかな人物が自宅やデスクでオンライン英会話を受講している雰囲気)を、トリミングでバストアップ〜上半身程度に収める想定(具体的な生成方針はSTEP07で決定)
- **背景装飾**: 淡いブルーの円形・小さなドット・会話を想起する吹き出し風モチーフを背景に配置してよい。ただし装飾過多にしない(FLEXIAの「単調な黒一色を避ける」演出とは異なり、こちらは「白一色にならない程度の軽い彩り」を目的とする)
- **情報量**: メインコピー・サブコピー・補足コピー・CTAのみに絞り、詰め込みすぎない
- **画面高さ**: `min-height: 85vh`程度を目安とし、100vh固定にはしない

**対象**: 「無料体験レッスンを予約する」

| font-weight | 700 |

## 9. アイコン方針

**方向性**: シンプルな線画(ストローク)アイコンで統一する。単色(Primary BlueまたはInverseカラー)を基本とし、Accent Orangeは数字バッジ・マーカー等の装飾的なワンポイントにのみ使用する。過度にカラフルな塗りつぶしアイコンは使用しない。

**実装方針**: 外部アイコンライブラリへの依存を増やさないため、必要なアイコン(人物・時計・PC/スマートフォン・カレンダー・会話吹き出し・チェック・シェブロン等)はインラインSVGとして自作・軽量化して用意する。著作権リスクのある既存アイコンセットの流用は避ける。

## 10. 画像・ビジュアル方針(STEP07へ引き継ぎ)

必要な画像は**2〜3点**とする(FLEXIA案件と同様、LPの大半はタイポグラフィ・アイコン・カードで構成し、画像点数を抑える)。

- **IMAGE01**: FVメインビジュアル。25〜39歳程度の社会人を想起させる、自然で爽やかな人物が、自宅やデスクでオンライン英会話を受講している雰囲気。縦長〜正方形程度を想定(比率はSTEP07で決定)
- **IMAGE02**: SECTION05受講スタイル用。PC・スマートフォンでオンラインレッスンを受けている様子を想起させるビジュアル、または人物の手元・デバイス操作の一部を切り取った構図
- **IMAGE03(任意・使用しない場合はIMAGE02のみで2点構成とする)**: 必要であれば、他セクションの雰囲気補助として1点追加を検討する。3点を超える追加は行わない

**人物表現の注意点(全画像共通)**:
- 実在人物・実在講師と誤認されない構図にする(顔の特徴を過度に強調しない、あるいは適度な距離感の構図にする)
- ブランドロゴ入りの服・背景を作らない
- 実在サービスのUI・ロゴ・特徴的な画面デザインを再現・模倣しない
- 明るく自然な印象の会社員層(過度に若すぎる・幼い印象は避ける)
- 架空のUI画面を描く場合、存在しない料金・実績・講師情報等を表示しない

**alt方針**: FLEXIA案件のSTEP08 QAでの知見を踏まえ、各画像が隣接するHTMLコピーと内容的に重複する装飾要素であるかどうかを実装時に判断する。重複する場合は`alt=""`+`aria-hidden="true"`の装飾画像として扱い、独立した情報を持つ場合は内容を説明するaltを設定する(最終判断はSTEP07のalt候補設定時に行う)。

## 11. アニメーション・インタラクション

- **fade-up**: 各セクション・カードがビューポートに入った際に、`opacity: 0 → 1` + `translateY(20px) → 0`で軽くフェードイン(IntersectionObserverベース)
- **subtle hover**: カード・ボタンのホバー時に`translateY(-2〜4px)`+shadow強調程度の控えめな動き
- **FAQ accordion**: `max-height`のCSSトランジションで開閉(0.25s ease程度)
- **header transition**: スクロール時にヘッダー背景の透明度・影をわずかに変化させる程度

**避けるもの**: パララックス、激しいスクロール演出、動画の自動再生、点滅、重いJavaScriptライブラリの導入、「無料」を煽る点滅・拡大演出。

**`prefers-reduced-motion`への配慮**: このメディアクエリが有効な場合、fade-up等のtransform/opacityトランジションを無効化し、要素を最初から表示状態にする。

## 13. アクセシビリティ

- **コントラスト**: 本文・見出しとも背景とのコントラスト比4.5:1(大きな見出しは3:1)以上を実装時に確認する。特にPrimary Blue(`#245DEB`)とAccent Orange(`#FFB547`)は、本章2.のルール(オレンジ/イエローを文字色として単独使用しない)を厳守する
- **focus-visible**: すべてのボタン・リンク・アコーディオントリガーに明確なフォーカスリングを設定する(色は背景に応じて`--color-primary`または白)
- **操作領域**: ボタン・タップ対象は44px前後以上を確保する
- **本文サイズ**: 16px前後以上を基本とし、Mobileでも15px以上を維持する
- **色だけに依存しない情報表現**: FAQの開閉状態など、色の変化だけでなくアイコンの向き・`aria-expanded`の状態変化でも情報を伝える
- **見出し階層**: h1→h2→h3の順を守り、階層を飛ばさない
- **FAQのaria属性**: トリガーに`aria-expanded`、パネルに対応する`id`と`aria-controls`、`role="region"`と`aria-labelledby`を設定する
- **keyboard操作**: すべての操作要素をTabキーで到達可能にし、アコーディオンはEnter/Spaceで開閉できるようネイティブ`<button>`を使用する
- **装飾画像と意味のある画像の区別**: 本章10.のalt方針に従い、実装時に個別判断する
- **`prefers-reduced-motion`**: 上記11章の通り、アニメーションを無効化するフォールバックを用意する

**STEP08で確認すべき注意点(申し送り)**:
- Mobile(375/390/430px)でのCTA文言の折返し・見出しの不自然な改行の有無
- Primary BlueとAccent Orangeの実際のコントラストが、実装後のCSSカスケード(特にSub Background上)で本章2.の計算通りになっているか
- セクション間余白がFLEXIA案件で発生した「モバイルでPC値が適用される」CSSカスケードの不具合を再発していないか
