## 1. LPの最重要ゴール

**確定情報**: LPの目的は無料体験レッスンの申込み獲得(client-brief.md記載)。

**最終CTA**: 無料体験レッスンを予約する

## 2. ターゲットの最重要課題

**確定情報**: 25〜39歳・会社員。仕事が忙しく、英語学習にまとまった時間を確保しづらい初心者。

**AIによる分析・仮説(02より)**: 「英会話初心者でレッスンについていけるか不安」「仕事が忙しく学習時間を確保しづらい」の2つが最も強い悩みであり、この2つは「初心者かつ忙しいため、始める・続けることへのハードルが高い」という1つの課題の裏表と捉えられる。

**提案**: 今回のLPで最も解決すべき課題を「初心者でも、忙しくても、会話練習を生活に取り入れやすい」に絞ることを提案する。client-brief.mdのサービス特徴(1回25分・オンライン完結・予約制・初心者向け・日本語サポート)、差別化方針(継続しやすさの訴求)と直接対応するため、この課題をLP全体の中心に据える。

## 3. コア訴求

**確定情報**: メインメッセージ「忙しい英語初心者でも、1回25分から会話練習を習慣にできる。」(client-brief.md記載)

**整合性の確認**: 上記メインメッセージは、02の最重要課題(初心者かつ忙しく始めづらい)・最も強い欲求(生活を大きく変えずに英語学習を習慣化し会話練習を継続できるようになる)と整合している。

**表現上の注意点(引き継ぎ)**: 「習慣にできる」は結果を保証する表現にしない。STEP05のコピー執筆では、「1回25分・オンライン完結・予約制」というサービス設計の特徴を根拠として「続けやすい」「取り入れやすい」ことを伝え、習慣化そのものを断定しない。

**USP(AIによる提案)**: 「初心者向け・マンツーマン・1回25分・オンライン完結・日本語サポートという設計により、忙しい会社員でも会話練習を生活に取り入れやすいオンライン英会話」。競合比較データがないため、「他社より優れている」「唯一」「業界No.1」といった比較優位表現は使用していない。

## 4. サブ訴求(確定情報のみを材料に整理)

- 初心者向け・マンツーマンで、自分のペースで取り組みやすい
- 1回25分で、忙しい生活にも取り入れやすい
- オンライン完結・PC/スマホ対応で、場所を選ばず受けやすい
- 日本語サポートがあり、初心者でも相談しやすい
- 無料体験レッスンがあり、気軽に試しやすい

## 5. サービス特徴 → ベネフィット

機能(確定情報)から想定されるベネフィットを、以下は**すべて仮説**として整理する。効果・上達度合いは断定しない。

| 確定特徴 | ベネフィット仮説 |
|---|---|
| 1回25分 | まとまった時間を確保しづらい会社員でも、生活に会話練習を取り入れやすい |
| マンツーマンレッスン | 周囲を気にせず、自分のペースで会話練習に取り組みやすい |
| オンライン完結 | 通学の移動なしで、自宅や職場からそのまま受けやすい |
| PC・スマートフォンから受講可能 | 特別な環境を用意せず、手持ちの機器で始めやすい |
| 日本語での学習サポートあり | 英語だけでは不安な初心者も、分からないことを相談しやすい |
| レッスン後に簡単なフィードバックあり | 受けっぱなしにせず、学習の振り返りがしやすい |
| 無料体験レッスンあり | 契約前に雰囲気を確認でき、試しやすい |
| 予約制 | 自分の都合に合わせてレッスンを組みやすい(「いつでも」「24時間」等への拡張はしない) |

## 6. ターゲット心理の変化(想定導線・仮説)

1. **不安**: 「英語を話せるようになりたいが、初心者で続けられるか不安」「忙しくて時間が取れるか分からない」
2. **自分にもできそう**: 「1回25分」「初心者向け」「日本語サポートあり」という確定特徴に触れ、ハードルの低さを感じる
3. **内容を理解**: マンツーマン・オンライン完結・予約制など、具体的なサービス設計を理解する
4. **試してみたい**: 無料体験レッスンの存在を知り、契約前に試せる安心感を得る
5. **無料体験レッスン申込み**: Webから申し込む、という確定した導線に沿って行動する

## 7. LP内で伝える情報の優先順位

1. コア訴求(忙しい英語初心者でも会話練習を取り入れやすい)とブランド名
2. ターゲットの悩みへの共感(初心者でついていけるか不安/忙しくて時間が取れない/独学では会話練習不足)
3. サービス特徴(1回25分・マンツーマン・オンライン完結・日本語サポート・フィードバック・予約制)
4. 特徴から得られる安心感・取り入れやすさ(ベネフィット)
5. 利用イメージ(レッスンの雰囲気を伝える、具体的な時間割・手順は作らない)
6. 無料体験レッスンへの導線(FAQで残る疑問を解消したうえで)
7. 最終CTA

## 8. ファーストビュー戦略

**方針**: 「忙しい会社員」「英語初心者」「1回25分」「始めやすさ」が短時間で伝わることを優先する。最終コピーは1案に確定せず、STEP04以降での検討候補として複数案を残す。

### メインコピー候補

**A案**: 「忙しい毎日に、25分の英会話習慣を。」
- 狙い: FLEXIA案件のメインコピーと近いリズムを踏襲しつつ、「習慣を」という名詞止めで、習慣化の"保証"ではなく"提案"として読める形にする
- 強み: 「忙しい」「25分」という核となる情報が短時間で伝わる。ブランドの継続性を感じさせる
- 注意点: 「習慣」という語が結果を連想させやすいため、直後の補足コピーで「無理なく続けられる設計」等、機能ベースの説明を添えて断定的な印象を薄める必要がある

**B案**: 「英会話初心者の一歩を、1回25分から。」
- 狙い: 「初心者」という最重要ターゲット属性と「1回25分」という時間の短さを同時に伝える
- 強み: 「一歩」という言葉で、大きな決断ではなく小さな最初の行動であることを示せ、心理的ハードルを下げやすい
- 注意点: 「一歩」が具体的に何を指すか(体験レッスンか学習全般か)が曖昧になりやすいため、サブコピーで無料体験への導線を明確にする必要がある

**C案**: 「忙しい社会人のための、25分間オンライン英会話。」
- 狙い: ターゲット(忙しい社会人)とサービス形式(25分・オンライン)を直接的かつ簡潔に説明する
- 強み: 誤解の余地が少なく、確定情報のみで構成できる最も安全な案
- 注意点: 直接的すぎて情緒的な訴求力(共感・安心感)がやや弱く、他の案と比べてインパクトに欠ける可能性がある

**D案**: 「仕事帰りの25分を、英会話の時間に。」
- 狙い: 「仕事帰り」という具体的な生活シーンを想起させ、生活への取り入れやすさをイメージさせる
- 強み: 情景が浮かびやすく、忙しい会社員という当事者性を感じさせやすい
- 注意点: 「仕事帰り」に受講時間を限定しているように誤読されるおそれがあるため、レッスン提供時間帯は未確定である旨を踏まえ、サブコピーや本文で受講タイミングを限定しない表現にする必要がある

**E案**: 「初心者から始める、1回25分のオンライン英会話。」
- 狙い: 「初心者」を主語に近い位置に置き、対象読者に強く語りかける
- 強み: 「初心者向け」という最重要の安心材料を最初に示せる
- 注意点: 「初心者から」がやや説明的で、A・B・D案と比べてキャッチコピーとしての引きは弱くなる可能性がある

**現時点の所感(AIによる提案、未確定)**: A案またはB案を軸にしつつ、C案の安全性・D案の情景喚起力も選択肢として残し、STEP04(LP構成)・STEP05(コピー執筆)で最終判断することを提案する。

### 使用可能な確定情報(ファーストビュー)

ブランド名(LUMIEL ENGLISH)、メインメッセージ方向性、サービス特徴(初心者向け・マンツーマン・1回25分・オンライン完結・日本語サポート・無料体験)、CTA文言「無料体験レッスンを予約する」。

## 10. 信頼感を作る方法(AIによる提案)

**前提(確定情報)**: 本案件は利用者数・満足度・実績数・口コミ・資格・受賞歴・有名企業導入・講師人数・講師国籍のいずれも設定しない架空LPである。

**提案**: 架空の社会的証明(実績・レビュー・資格等)は一切作らず、以下の情報の透明性で信頼感を作ることを提案する。
- サービス内容を具体的に説明する(1回25分・マンツーマン・オンライン完結・日本語サポート・フィードバック・予約制)
- レッスンの流れ・利用イメージを分かりやすく伝える(架空の詳細タイムスケジュールは作らない)
- 初心者向けであることを明確に打ち出し、対象読者に安心感を持たせる
- 無料体験レッスンの存在自体を、契約前に試せる透明性として提示する
- 架空制作であることをフッター等で明示し、誠実な情報開示として扱う

**オファー設計**: 確定しているオファーは「無料体験レッスン」のみ。料金・割引・入会特典・キャンペーンは設定しない。無料体験を「契約前に内容を確認できる場」として位置づけ、申込みへの心理的ハードルを下げる導線としてCTAに使うことを提案する。**「勧誘なし」「営業されません」「無理な勧誘はいたしません」などの保証は、client-brief.mdに記載がないため付けない。**

## 11. 掲載しない情報

- 講師人数・講師の国籍・経歴・資格
- 利用者数・満足度・継続率・実績数
- 受講者の声・口コミ
- 資格・受賞歴・有名企業導入実績
- 効果保証表現(「必ず話せるようになる」「絶対に上達する」「100%」「業界No.1」「最短○日でペラペラ」等)
- 競合比較による優位性の断定
- 24時間対応、予約可能時間の具体的な範囲、「いつでも予約可能」等の予約制からの拡張表現
- キャンセル条件、教材内容、レッスン提供時間帯の詳細
- 無料体験後の勧誘方針(「勧誘なし」「営業されません」等を含む)

## 12. LP全体のストーリー(AIによる提案)

以下の流れでLP全体を構成することを提案する(セクション詳細はSTEP04で設計する)。

1. **共感**: ターゲットの悩み(初心者でついていけるか不安、忙しくて時間が取れない、独学では会話練習不足、サービス選びに迷う)に共感を示す
2. **自分向けだと理解**: 忙しい会社員・英語初心者向けのサービスであることを伝える
3. **サービス内容を理解**: 初心者向け・マンツーマン・1回25分・オンライン完結・日本語サポートという特徴を伝える
4. **不安を解消**: サービス内容の透明性、利用イメージ、無料体験の位置づけを示す
5. **無料体験レッスンへ進む**: 心理的ハードルの低いCTAで申込みを後押しする
