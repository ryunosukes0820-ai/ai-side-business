# LP Strategy — FLEXIA Personal Gym LP

**凡例**: 本文書内では以下を区別して明記する。
- **確定情報**: client-brief.mdに記載されている事実
- **AIによる分析・仮説**: 02_target_analysis.mdで整理した心理・障壁(実際の顧客調査ではない)
- **AIによる提案**: STEP03でAIが考案した訴求・導線・オファーの方向性(クライアント決定済みの方針ではない)

料金・割引・キャンペーン・実績・満足度・継続率・顧客レビュー・トレーナー資格・店舗所在地・ビフォーアフター・利用人数・成功率・医学的効果・断定的な結果保証表現・No.1表現は、本文書内で一切使用していない。

## 1. LPの目的

**確定情報**: LPの目的は無料カウンセリングの申込み獲得(client-brief.md記載)。

**最終CTA**: 無料カウンセリング申込み

## 2. メインターゲット

**確定情報**: 25〜39歳・会社員・男性メイン。仕事が忙しく、平日は運動時間を確保しづらい。

**AIによる分析・仮説(02より)**: 短時間で効率よく取り組みたいという価値観を持つ可能性がある。一人でのトレーニングに迷いを感じ、明確な指示・伴走を求める傾向がある可能性がある。

## 3. 最重要課題(AIによる提案)

**提案**: 今回のLPで最も解決すべき課題を「忙しくて運動習慣を続けられない」に絞ることを提案する。

**02_target_analysis.mdとのつながり**: STEP02では「最も強い悩み」として「継続できない」と「仕事が忙しく運動習慣を作れない」の2つが挙げられているが、この2つは「忙しさゆえに続けられない」という1つの課題の裏表と捉えられる。また、client-brief.mdのサービスの強み(忙しい会社員でも継続しやすいサービス設計)、差別化方針(短期間で痩せる訴求ではなく継続しやすさを訴求)とも直接対応するため、この課題をLP全体の中心に据えることを提案する。

## 4. メイン訴求

**確定情報**: メインメッセージ「忙しい毎日に、週2回の身体改革。」、補足メッセージ「完全マンツーマンだから、迷わない。仕事帰り60分から始めるパーソナルトレーニング。」(client-brief.md記載)

**整合性の確認**: 上記メインメッセージは、STEP02の最重要課題(忙しくて続けられない)・最も強い欲求(生活を大きく変えずに運動習慣を作り自信を持てる身体を目指す)と整合している。

**AIによる提案(方向性、最終コピーは未確定)**:
- A案(client-brief.md案をそのまま採用): 「忙しい毎日に、週2回の身体改革。」
- B案(生活を変えない点を強調): 「今の生活のままで、変わっていく。」
- C案(迷わず始められる安心感を強調): 「迷わず続けられる、はじめてのパーソナル。」

いずれも方向性の提案であり、最終コピーはSTEP05(LP本文執筆)で確定する。

## 5. サブ訴求(確定情報のみを材料に整理)

- 完全マンツーマンで迷わない
- 1回60分、仕事帰りにも取り入れやすい
- 週2回を想定した、継続しやすいサービス設計
- 食事アドバイスも受けられる
- ウェア・タオル無料レンタル

## 6. USP(AIによる提案)

**提案**: 「忙しい会社員が、生活を大きく変えずに運動を続けやすいことを重視した、完全マンツーマンパーソナルジム」

**根拠**: 完全マンツーマン・週2回想定・仕事帰り60分・食事アドバイスという、client-brief.mdに確定情報として記載された特徴の組み合わせをUSPとする。競合比較データがないため、「他社より優れている」「唯一」「No.1」といった比較優位表現は使用していない。

## 7. ベネフィット

機能(確定情報)から想定されるベネフィットを、以下は**すべて仮説**として整理する。医学的・身体的な効果(減量量、体型変化など)は断定しない。

- 機能: 完全マンツーマン → ベネフィット仮説: 何をすればいいか迷いにくく、トレーニングに取り組みやすい
- 機能: 週2回想定 → ベネフィット仮説: 忙しい生活の中でも無理なく続けやすい
- 機能: 1回60分・仕事帰りでも利用しやすい設計 → ベネフィット仮説: 生活リズムを大きく変えずに運動を取り入れやすい
- 機能: 食事アドバイス → ベネフィット仮説: 運動以外の生活面も含めて相談できる安心感を得やすい
- 機能: ウェア・タオル無料レンタル → ベネフィット仮説: 持ち物の準備の負担が減り、始めるハードルが下がりやすい

## 8. 信頼獲得方針(AIによる提案)

**前提(確定情報)**: 本案件は実績・お客様の声・資格情報・店舗所在地のいずれも設定しない架空LPである。

**提案**: 架空の社会的証明(実績・レビュー・資格等)は一切作らず、以下の情報で信頼感を作ることを提案する。
- サービス内容の透明性(確定しているサービス特徴・提供内容を分かりやすく提示する)
- 確定情報の範囲で、無料カウンセリングへの申込み方法・導線を分かりやすく提示する(client-brief.mdに存在しない申込み後の詳細な流れを補完しない)
- 架空制作であることをフッター等で明示し、誠実な情報開示として扱う

## 9. オファー設計

**確定情報**: 確定しているオファーは「無料カウンセリング」のみ。料金・割引・入会特典・キャンペーンは設定しない。

**AIによる提案**: 無料カウンセリングを「契約前に相談できる場」として位置づけ、申込みへの心理的ハードルを下げる導線としてCTAに使うことを提案する。**「無理な勧誘なし」「当日入会不要」などの保証は、client-brief.mdに記載がないため付けない。**

## 10. CTA設計(AIによる提案)

**最終CTA(確定情報)**: 「無料カウンセリングを予約する」

**配置候補(提案)**:
- FV
- サービス説明後
- 利用の流れ周辺
- FAQ後
- 最終セクション

上記の配置はAIによる提案であり、詳細な確定はSTEP04(LP構成設計)で行う。

## 11. LP全体のストーリー(AIによる提案)

以下の流れでLP全体を構成することを提案する(セクション詳細はSTEP04で設計する)。

1. **共感**: ターゲットの悩み(忙しくて続けられない、一人だと迷う)に共感を示す
2. **自分向けだと理解**: 忙しい会社員向けのサービスであることを伝える
3. **サービス内容を理解**: 完全マンツーマン・週2回想定・60分・仕事帰りという特徴を伝える
4. **不安を解消**: サービス内容の透明性、利用の流れ、無料カウンセリングの位置づけを示す
5. **無料カウンセリングへ進む**: 心理的ハードルの低いCTAで申込みを後押しする

## 12. STEP04へ引き継ぐ重要事項

- **最重要課題**: 忙しくて運動習慣を続けられない
- **メイン訴求候補**: A「忙しい毎日に、週2回の身体改革。」/ B「今の生活のままで、変わっていく。」/ C「迷わず続けられる、はじめてのパーソナル。」(いずれも未確定)
- **サブ訴求**: 完全マンツーマン / 1回60分・仕事帰り可 / 週2回想定で継続しやすい設計 / 食事アドバイス / ウェア・タオル無料レンタル
- **USP候補**: 「忙しい会社員が、生活を大きく変えずに運動を続けやすいことを重視した、完全マンツーマンパーソナルジム」
- **主な心理障壁(仮説)**: 継続できるかへの不安 / 自分に合うか分からない不安 / 時間を確保できるかへの不安 / 強引な勧誘への懸念
- **信頼獲得方針**: サービス内容の透明性、確定情報の範囲での申込み導線の明示(存在しない詳細は補完しない)、架空制作である旨の明示(架空の社会的証明は作らない)
- **CTA方針**: 最終CTA文言「無料カウンセリングを予約する」を、FV/サービス説明後/利用の流れ周辺/FAQ後/最終セクションの5箇所に配置する案(STEP04で確定)
