# 01. Brief Analysis — FLEXIA Personal Gym LP

## 1. 案件概要

FLEXIA(架空ブランド)のパーソナルジム「FLEXIA PERSONAL GYM」のLP制作案件。**ポートフォリオ掲載用の架空制作**であり、実在する店舗・企業ではない。

## 2. LPの目的

無料カウンセリングの申込み獲得。CTA文言は「無料カウンセリングを予約する」。

## 3. 確定している情報

- 会社・ブランド名: FLEXIA
- 業種: パーソナルジム
- 商品・サービス名: FLEXIA PERSONAL GYM
- サービス概要: 完全予約制のマンツーマンパーソナルトレーニング
- サービス特徴: 1回60分 / 完全マンツーマン / 週2回想定 / 食事アドバイス / ウェア・タオル無料レンタル / 仕事帰りでも利用しやすい設計
- 強み: 忙しい会社員でも継続しやすいことを重視したサービス設計
- 差別化方針: 「短期間で劇的に痩せる」ではなく「無理なく継続できる」ことを中心に訴求する
- 申込方法: Webから無料カウンセリングを申し込む
- メインメッセージ: 「忙しい毎日に、週2回の身体改革。」
- 補足メッセージ: 「完全マンツーマンだから、迷わない。仕事帰り60分から始めるパーソナルトレーニング。」
- 希望カラー: ブラック / ホワイト / 鮮やかなブルー
- 希望テイスト: 高級感・都会的・スタイリッシュ・男性向け・清潔感・スポーティー・モダン
- 避けたいデザイン: 過度にマッチョな印象 / 赤と黒だけの攻撃的なデザイン / 安売り感 / 過剰なビフォーアフター / 情報を詰め込みすぎたデザイン
- 素材方針: ロゴは後工程で制作予定、写真・人物画像はAI生成予定、商品画像はなし、必要に応じてアイコン・抽象グラフィックを使用
- **架空サービスである旨を、LPのフッター等で分かるように明記する必要がある**(brief指定)

## 4. ターゲットとして確定している情報

- 年齢: 25〜39歳
- 性別: 男性をメインターゲット
- 職業: 会社員
- 生活スタイル: 仕事が忙しく平日は運動時間を確保しづらい。仕事帰り・休日を使って効率よく身体を整えたい
- 主な悩み: ジムに入会しても継続できない / 自分に合ったトレーニング方法が分からない / 仕事が忙しく運動習慣を作れない / 体型を引き締めたい / 一人でトレーニングすると何をすればいいか迷う
- 理想の状態: 忙しい生活を大きく変えずに運動習慣を作り、自信を持てる身体を目指す

## 5. サービスとして確定している情報

上記3と重複するため要点のみ再掲: 完全予約制・マンツーマン・60分・週2回想定・食事アドバイス・ウェア/タオル無料レンタル・仕事帰りでも利用しやすい設計。**料金体系(月謝/回数券/セット価格など)は未定義**。

## 6. 不足している情報

### 6-1. 制作を止める必要がある不足情報

**現時点ではありません。** 料金・対応エリア(店舗所在地)・実績・お客様の声・資格は、briefにおいて「架空LPのため設定しない」「後工程でも勝手に作らない」と**意図的に空欄にする方針が明記**されており、情報不足による制作停止事由には該当しないと判断します。

### 6-2. 現時点では未確定のまま進められる情報

- 料金(**確定情報**: 具体的な金額は未設定。**AIによる提案の余地**: LP上での料金の見せ方・表現方法については後工程で提案可能だが、現時点では確定情報として扱わない)
- 対応エリア・店舗所在地(具体的な地域・住所は設定しない)
- 実績・継続率・満足度などの数値(設定しない)
- お客様の声(掲載しない)
- トレーナー資格(設定しない)
- 参考サイト(未設定のまま進める)
- ロゴ(後工程で制作予定。現段階のデザイン仕様書・実装ではプレースホルダーとして扱う)
- 写真・人物画像(AI生成予定。07_image_promptsで生成プロンプトを作成する)

## 7. 仮定してはいけない情報

briefで明示的に捏造禁止とされている項目:

- 利用者数 / 売上 / 満足度 / 継続率 / ダイエット成功率
- 受賞歴 / トレーナー資格
- 店舗所在地
- 顧客レビュー
- ビフォーアフター実績
- 医学的効果 / 結果保証

および、briefで未確定の以下の項目も、後工程で憶測により補完しない:

- 具体的な料金・金額
- 具体的な対応エリア・住所

以下の断定・誇大表現も使用しない(brief指定): 「必ず痩せる」「絶対に変わる」「100%」「短期間で○kg減」「業界No.1」

## 8. 制作時のリスク・注意点

- **実在のジム・店舗・企業との誤認防止**: フッター等に「本サイトはポートフォリオ制作用の架空サービスです」といった趣旨の明記が必須
- **YMYL的配慮**: パーソナルトレーニング・ダイエット領域は健康に関わるため、医学的効果を断定する表現、結果を保証する表現は使用しない
- **料金の扱い(確定情報とAI提案の分離)**: 確定情報は「具体的な料金は未設定」「無料カウンセリング申込みが最終CTA」のみ。料金をLP上でどう見せるか、料金未設定のままどのような導線・表現にするかはclient-brief.mdで確定しておらず、STEP03以降でAIが提案する余地として扱う。特定の導線(カウンセリングでの案内、詳細説明への誘導など)を、この時点で確定事項として決め打ちしない
- **ターゲット表現の配慮**: 「男性をメインターゲット」であって「男性限定」ではないため、女性を明示的に排除するような表現・ビジュアルは避ける
- **素材の未確定**: ロゴ・写真・人物画像が現段階で存在しないため、デザイン仕様書・実装は「素材確定後に差し替え可能」な前提で設計する

## 9. STEP02以降へ引き継ぐ重要事項

- ターゲットの悩み(継続できない/自分に合う方法が分からない/忙しくて運動習慣がない/体型を引き締めたい/一人だと迷う)と理想の状態を、ターゲット分析(02)のインプットの中心に据える
- メインメッセージ「忙しい毎日に、週2回の身体改革。」と補足メッセージを、LP訴求(03)のコアメッセージとして維持する
- 差別化方針(短期間訴求ではなく継続しやすさ訴求)を、USP設計(03)にそのまま反映する
- 料金・実績・所在地・お客様の声・資格について、確定情報は「具体的な金額・数値・固有名詞は未設定」のみ。これらをLP上でどう見せるか(掲載しない、無料カウンセリングで案内する等の具体的な導線・表現)はclient-brief.mdで確定しておらず、STEP03(LP戦略設計)以降でAIが提案し、人間の確認を経て決定する事項として扱う
- 禁止表現リスト(必ず/絶対/100%/短期間で○kg減/業界No.1、および利用者数・売上等の捏造数値)を、05のLP本文執筆まで一貫して適用する
- 「架空サービスである旨の明記」を、04のLP構成の段階でフッター等のセクションに明示的に組み込む
