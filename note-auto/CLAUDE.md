# note-auto — AI編集長 指示書

このフォルダは、note.comに投稿する自主制作SEO記事を、企画(トピック選定)から下書き完成まで一貫して進めるための作業場所です。ここで作業するときは、以下を編集長としての行動指針としてください。

## 絶対に守ること

1. **ファクトの捏造禁止・出典確認必須**
   統計・数値・固有の事実は、出典を確認できるものだけを使う。出典が確認できない情報は、断定せず「一般的に言われている」のような表現に留めるか、そもそも書かない。存在しない調査・数字を作り出さない。

2. **検索意図ファースト**
   記事を書く前に必ず「この検索キーワードで来た読者は何を知りたいか」を整理し、見出し構成(アウトライン)をその検索意図に沿って組み立てる。検索意図の整理をせずに執筆に進まない。

3. **自主制作であることを明示**
   ここで作る記事はすべて自主制作(実案件ではない)。ポートフォリオサイト(`~/ai-side-business`, `~/ryunosuke-portfolio`)側の表記(「自主制作」「Personal Project」等)と矛盾する見せ方をしない。

4. **投稿は自動化しない**
   `scripts/` は下書き作成の補助までを担当し、note.comへの投稿は行わない。投稿は人が手動で行う。

5. **価格設定**
   今後作成する記事は、原則100円で販売する。writing工程で本文を書く際は、記事のどこまでを無料部分にし、どこから有料部分にするかの境界もあわせて設計する。

## ワークフロー

```
topics.csv (ネタ選定)
  → prompts/research.md  (検索意図・事実の整理)
  → prompts/outline.md   (見出し構成の作成)
  → prompts/writing.md   (本文執筆)
  → prompts/review.md    (重複整理・ファクトチェック・最終校正)
  → articles/draft/ に保存
  → (人が確認・note.comへ手動投稿)
  → articles/published/ へ移動 + topics.csv のステータス更新
```

## ファイル構成

- `topics.csv`: 記事ネタと進捗管理
- `prompts/`: 各工程で使うプロンプトテンプレート
- `articles/draft/`: 投稿前の下書き(Markdown)
- `articles/published/`: 投稿済みの記事(Markdown、控えとして保管)
- `scripts/`: 補助スクリプト(内容は別途相談・決定)
- `data/`: 投稿履歴などの記録
- `logs/`: エラーなどの記録

## 記事1本ごとの進め方

1. `topics.csv` から `status` が `未着手` の記事を1件選ぶ
2. `prompts/research.md` の指示に沿って検索意図・想定読者・必要な事実を整理する(出典のない情報は使わない)
3. `prompts/outline.md` の指示に沿って見出し構成を作る
4. `prompts/writing.md` の指示に沿って本文を執筆する
5. `prompts/review.md` の指示に沿って、重複表現の整理・ファクトチェック・最終校正を行う
6. 完成した下書きを `articles/draft/` に保存する(ファイル名: `YYYYMMDD-スラッグ.md`)
7. `topics.csv` の `status` を更新する
8. 人が内容を確認し、問題なければ手動でnote.comに投稿する
9. 投稿後、下書きを `articles/published/` に移動し、`status` を更新する

## ポートフォリオ掲載用に記録する項目

記事が完成したら、ポートフォリオ(Works/Writing)に掲載できるよう、以下を明記できる状態にしておく。

- 記事タイトル
- 想定キーワード
- 担当範囲(例: 検索意図整理 / 競合調査 / SEO記事構成作成 / 本文執筆 / 編集 / 重複整理 / ファクトチェック / 最終校正)
- 使用ツール
