# Outline プロンプト

**目的**: `research.md` で整理した検索意図をもとに、見出し構成(アウトライン)を作る。

## 使い方

`research.md` の出力(検索意図・想定読者・使ってよい事実)を渡した上で、以下のプロンプトを使う。

---

あなたはSEO記事の構成作成担当です。以下のリサーチ結果をもとに、見出し構成(アウトライン)を作成してください。

- トピック: {{title}}
- 想定キーワード: {{keyword}}
- リサーチ結果: {{research_output}}

以下の方針で構成してください。

1. **検索意図に沿った順番**にする(読者が知りたい順に見出しを並べる。書き手が話したい順ではない)
2. タイトル(H1相当)、リード文で書く内容、H2・H3の見出し案を出す
3. 各見出しで「何を伝えるか」を1行で添える
4. 記事の最後に、読者が次に取るべき行動(まとめ・次のステップ)を明記する
5. `research.md` で「不確実な情報」に分類したものは、見出し・本文の根拠に使わない

## チェックリスト

- [ ] 見出しの並びが検索意図の優先順位と一致しているか
- [ ] 見出しだけを読んでも記事の流れが分かるか
- [ ] 出典のない事実を前提にした見出しになっていないか
