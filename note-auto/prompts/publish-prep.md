# Publish-prep プロンプト

**目的**: `review.md` で仕上げた最終稿をもとに、note投稿用のメタ情報と、サムネイル設計案を作成する。

**この工程はすべての記事で必須。** サムネイル設計案(下記4項目)が作成できていない場合、その記事は「公開準備完了」とはみなさない。

## 使い方

review後の最終稿を渡した上で、以下を作成する。

---

## 0. 本文への管理用マーカー挿入禁止(重要)

記事本文には、有料ライン候補などの内部管理用コメント・マーカーを**一切挿入しない**。HTMLコメント(`<!-- -->`)、Markdownコメント、その他note上に表示される可能性があるマーカーもすべて禁止する。

無料/有料の境界は、`outline.md` で決めたテキストの説明(例: 「ステップ1の末尾、ステップ2見出しの直前」)を、下記の「note投稿用メタ情報」と、ワークフローの最終報告の両方に記録する。本文ファイル自体は、そのままnoteに貼り付けても問題ない、境界だけの純粋な本文にする。

## 1. note投稿用メタ情報

- **投稿用タイトル**: `outline.md` で確定したSEOタイトルをそのまま使う
- **本文の文字数**: `review.md` で確認した最終文字数を記録する(第7記事以前には不要。2,800〜3,200文字ルールが適用される第8記事以降で必須)
- **有料ラインの位置**: `outline.md` で決めた境界を、見出し名を使ったテキストで記録する(例: 「ステップ1の末尾、ステップ2見出しの直前」)。本文には一切マーカーを挿入しない
- **投稿用本文**: 記事本文をそのまま使う(本文中に管理用マーカー・コメントが存在しないため、除去作業は発生しない)。noteにそのまま貼り付けられる状態にしておく
- **ハッシュタグ案**: 3〜5個。メインキーワードとカテゴリをもとに、note上で実際に使われそうな一般的なタグを提案する。記事内容と無関係なタグ、誇張的なタグは付けない

## 2. サムネイル設計案(必須・4項目すべて作成する)

1. **メインテキスト**: サムネイル画像に大きく載せる短いコピー。記事タイトルの要点を凝縮したもの
2. **サブテキスト**: メインテキストを補足する短い一文(不要と判断した場合はその理由を添えて省略可)
3. **デザイン案**: 配色・レイアウト・雰囲気の方向性。既存記事のサムネイルとのトーンの一貫性も考慮する
4. **画像生成AI用プロンプト**: 上記1〜3を反映し、画像生成AIにそのまま渡せる形で書いたプロンプト(特定の生成AIサービスに依存しない一般的な記述にする)

### 作成方針

- **検索キーワードとの一致**: メインテキストに、メインキーワードの要素が含まれているか確認する
- **スマホでの視認性**: 文字数を絞る(メインテキストは日本語で15〜20字程度を目安)。小さい画面でも読める分量にする
- **クリックしたくなる分かりやすさ**: 「何についての記事か」が一目で伝わる表現にする
- **誇張表現の禁止**: 「絶対」「これだけで」のような過度な煽り、本文の内容と一致しない表現は使用しない

### 出力形式

記事本文(最終稿)の末尾に、以下の形式で追記する。

```markdown
---

## note投稿メタ情報

**投稿用タイトル**: ...

**本文の文字数**: ...文字

**有料ラインの位置**: (例: 「ステップ1の末尾、ステップ2見出しの直前」。本文中にマーカーは挿入しない)

**ハッシュタグ案**: #... #... #...

## サムネイル設計案

- メインテキスト: ...
- サブテキスト: ...
- デザイン案: ...
- 画像生成AI用プロンプト: ...
```

## 必須チェック(公開準備完了の条件)

- [ ] メインテキスト・デザイン案・画像生成AI用プロンプトの3項目(サブテキストは省略可)が作成されているか
- [ ] メインテキストにメインキーワードの要素が含まれているか
- [ ] メインテキストがスマホでも読める文字数(目安15〜20字)に収まっているか
- [ ] 誇張表現・内容と不一致な表現がないか
- [ ] 本文中にHTMLコメント・Markdownコメントなど、管理用マーカーが一切残っていないか(そのままnoteに貼り付けて問題ない状態か)
- [ ] 有料ラインの位置が、本文中のマーカーではなく「note投稿メタ情報」にテキストで記録されているか
- [ ] 本文の文字数が2,800〜3,200文字の範囲内で、「note投稿メタ情報」に記載されているか(第7記事以前は対象外)

このチェックが満たされていない状態は、`articles/draft/` に保存はできても「公開準備完了」とは扱わない。
